# v1.27.0-hcpclusters.1

## Changes by Kind

### Feature

- ARO-HCP support now uses the `2026-10-01` GA API while retaining the `2026-09-01-preview` API for existing resources.
- Update the Azure Service Operator dependency to `v2.23.0-hcpclusters.1` and register the GA API storage types.
- Preserve agent pool profile settings for artifact streaming, local DNS, and node image version when reconciling managed clusters.
- Update Azure managed cluster support to the `2026-05-01` API.

## Details

This release is based on upstream v1.27.0 with ARO-HCP support.

Base upstream version: v1.27.0
ASO version: v2.23.0-hcpclusters.1
ARM API versions: 2026-09-01-preview, 2026-10-01
